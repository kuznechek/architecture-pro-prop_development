## Требования безопасности для интеграции с платформой Smart Home

### Требования к безопасности

* Обеспечение безопасности передачи данных с помощью HTTPS с TLS 1.3
* Firewall
* Логирование взаимодействия между партнёрскими сервисами
* Асинхронность операций с партнёрскими сервисами (для повышения отказоустойчивости PropDevelopment)
* Данные о биометрии находятся в ведении партнёрского сервиса
* При регистрации в системе каждый пользователь подписывает согласие на обработку даных

### Протоколы аутентификации и авторизации

### Аутентификация PropDevelopment в платформе Smart Home

* OAuth 2.0
* MFA
* Access Token имеют фиксированное время жизни

### Взаимодействие между системами предприятия и внешней платформой

#### Действия пользователя в приложении :

* Авторизация/регистрация пользователя в PropDevelopment
* Меню Smart Home:
    * Управление доступными умными устройствами
    * Добавление нового умного устройства
    * Удаление умного устройства
    * Добавление новых данных в профиль (биометрия лица, в будущем: отпечатки пальцев, запись голоса и так далее)

#### Физическое взаимодействие пользователя с устройствами :

* Автоматическая работа шлагбаума/домофона
    * Камера интеллектуального шлагбаума/домофона распознала лицо и передаёт данные в SmartHomeService
    * SmartHomeService принимает решение о том, впускать ли пользователя
    * SmartHomeService получает OAuth токен у SmartHome
    * Формирует команду на открытие
    * Пишет логи
    * Открывает шлагбаум/дверь
